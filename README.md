# Git Workshop: Collaborative Calculator

Welcome to the Git workshop! 🎉  
In this exercise, you will work in **pairs** to practice collaboration with Git and GitHub while implementing a simple Java calculator.  

The tasks are simple programming problems in Java — but the main goal is to **experience collaboration**, including branching, pull requests, and resolving merge conflicts.  

---

## 🎯 Goals
- Work on **feature branches**
- Push and pull changes from a shared repo
- Experience and resolve **merge conflicts**
- Open and review **pull requests**
- Practice basic teamwork in Git

---

## ⚙️ Setup
1. One of you forks this repository into your GitHub account.
2. Add your partner as a **collaborator** (Settings → Collaborators).
3. Both of you clone the repo locally:
   ```bash
   git clone <your-fork-url>
   cd git-workshop-calculator
4. Compile and run the starter program to check it works:
   ```bash
   javac src/Calculator.java
   java -cp src Calculator
   ```

Check out the issues in this repository, copy them to your own clone of the project and assign them to each of you - One of you will be Student A and the other will be Student B.
